## 界面与使用

### 第一步：运行程序
双击 `N_m3u8DL-CLI.exe` 即可打开窗口。

### 第二步：三步完成下载
1. 在「下载链接」中粘贴 `m3u8` / `mpd` / 视频直链地址；
2. 点击「开始下载」；
3. 下载完成后，视频保存在程序目录下的 `Videos` 文件夹里（点界面上的「打开」按钮可直接打开该文件夹）。

### 界面元素说明

| 位置 | 名称 | 说明 |
| --- | --- | --- |
| 顶部 | 下载链接 | `m3u8` / `mpd` / 直链地址，必填 |
| 顶部 | 保存名称 | 可选；留空则自动按时间命名 |
| 顶部 | 线程 | 同时下载的分片线程数，默认 32 |
| 顶部 | 限速KB/s | `0` 表示不限速；例如填 `500` 表示限制为 500 KB/s |
| 顶部 | 代理 | 可选，支持 `http://` 与 `socks5://` |
| 顶部 | 保存目录 | 默认 `Videos`，可自行修改 |
| 顶部 | 请求头 | 可选，每行一个，如 `Referer: https://example.com` |
| 顶部 | 开始下载 | 新建下载任务，可同时下多个，程序不会自动关闭 |
| 顶部 | 停止选中 / 删除选中 / 清空已完成 | 管理任务列表 |
| 顶部 | 完成后删除临时分片文件 | 勾选后只保留最终视频 |
| 中部 | 任务列表 | 名称 / 进度 / 速度 / 状态 / 地址；选中一行即可看下方详情，双击一行可直接打开它的保存文件夹 |
| 下部 | 进度条与速度 | 显示所选任务的实时进度、下载速度与剩余时间 |
| 下部 | 状态色块 | 随状态变色：灰=未开始、蓝=下载中、绿=完成、橙=已停止、红=失败 |
| 下部 | 下载信息区 | 每条日志前带颜色色块：灰=信息、绿=成功、橙=警告、红=失败 |
| 底部 | 状态栏 | 左下角 `开发者:NIL`，右下角 `version:1.0.0` |

## 目录结构

文件夹即完整可运行的程序，外层只保留四项，其余依赖都收在 `bin` 中：

```
N_m3u8DL-CLI\
├── N_m3u8DL-CLI.exe      ← 运行程序（双击打开界面）
├── Videos\               ← 下载的视频保存在这里
├── 使用说明.txt
├── 界面预览.png
└── bin\                  ← 运行所需的依赖文件，请勿删除
    ├── ffmpeg.exe                     (合并视频必需)
    ├── Newtonsoft.Json.dll
    ├── CommandLine.dll
    ├── NiL.JS.dll
    ├── BrotliSharpLib.dll
    ├── MihaZupan.HttpToSocks5Proxy.dll
    ├── UACHelper.dll
    ├── System.Runtime.CompilerServices.Unsafe.dll
    ├── logo_3Iv_icon.ico              (窗口图标)
    └── NO_UPDATE
```

> 整个文件夹可随意复制到任意位置（桌面、其他盘、U 盘等）独立运行；

## 运行环境

* Windows 7 SP1 / 8.1 / 10 / 11
* .NET Framework 4.6 或更高版本（Windows 10 / 11 通常已自带）
* 无需额外安装 ffmpeg —— 已随程序放在 `bin\ffmpeg.exe`

## 从源码构建

仓库中不包含编译产物，可按下列步骤自行构建：

1. 运行 `fetch-deps.ps1`（**需要联网，仅首次执行**）
   该脚本会下载 Roslyn 编译器（`csc.exe`）以及项目依赖的 NuGet 包，分别放入 `tools\` 与 `libs\`。
2. 运行 `build.ps1`
   编译生成 `dist\` 目录（含 `N_m3u8DL-CLI.exe` 与 `bin\` 依赖）。
   若本机 `PATH` 中存在 `ffmpeg.exe`，脚本会自动复制到 `dist\bin\`。

也可以直接使用 Visual Studio 打开 `N_m3u8DL-CLI.sln` 编译（需自行还原 NuGet 包）。

## 兼容命令行

本程序在**无参数启动**时打开图形界面，在**带参数启动**时仍兼容原命令行用法：

```bat
N_m3u8DL-CLI.exe "https://example.com/playlist.m3u8" --workDir "E:\video" --saveName "abc"
```

完整的命令行参数说明请参见原项目文档（见下方「来源与致谢」）。
